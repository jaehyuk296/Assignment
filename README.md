# Assignment 과제 레포지토리

이 레포지토리는 프론트엔드와 백엔드 과제 폴더로 구성되어 있습니다.  
각 주차별 과제는 해당 폴더 내에 주차별로 관리됩니다.

## 폴더 구조

```
Assignment/
│
├── frontend/   # 프론트엔드 과제 폴더
│
└── backend/    # 백엔드 과제 폴더
```

---

## 과제 진행 방식

1. **레포지토리 클론**  
   본 레포지토리를 자신의 로컬 환경에 클론합니다.

2. **개발 환경 세팅**  
   각 폴더(`frontend`, `backend`)의 README.md를 참고하여 환경을 세팅합니다.

3. **브랜치 생성**  
   브랜치 이름은 `feat/분야/이름/과제주차` 형식으로 생성합니다.  
   예시: `feat/backend/홍길동/1주차`

4. **과제 수행**  
   각자 브랜치에서 과제를 수행합니다.

5. **커밋 및 푸시**  
   작업 완료 후 커밋하고 원격 저장소에 푸시합니다.

6. **Pull Request 생성**  
   `main` 브랜치로 PR을 생성합니다.  
   PR 제목: `feat/분야/이름/과제주차`  
   PR 설명: 과제 설명 및 해결한 단계 간단히 작성

---

## 폴더별 안내

### backend/

- FastAPI 기반의 백엔드 과제
- 개발환경 세팅, 실행 방법, 예제 등은 `backend/README.md` 참고
- 1주차 과제 예시 및 목업 데이터, HTML 템플릿 예제 포함

### frontend/

- 프론트엔드 과제(추후 추가 예정)
- 별도 안내가 있을 경우 해당 폴더의 README.md 참고

---

## 백엔드 1주차 과제 안내

- FastAPI 기본 예제, uv 기반 개발환경 세팅, uv 세팅 가이드 제공
- 목업 데이터는 `backend/data/` 폴더에 JSON 파일로 저장
- 웹페이지는 `backend/templates/` 폴더에 HTML 파일로 저장
- 다양한 FastAPI 예제 코드(HTML 렌더링, JSON 반환, 파라미터 처리 등) 포함
- 자세한 내용은 `backend/README.md` 참고
